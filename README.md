# PixelTap — сайт марки

Официальный сайт PixelTap: pixeltapi.ru. Статический, без фреймворков.
Сайт не магазин: у каждого товара кнопки на карточки Ozon и Wildberries.

```
site/            исходники страниц: шаблоны, стили, скрипты, шрифты, картинки
  index.html       главная
  lanolin/         посадочная «Ланолин»
  privacy/         конфиденциальность
  404.html
  partials/        шапка, подвал, вопросы-ответы
  htaccess.tpl     заголовки безопасности и редиректы для Timeweb
data/catalog.json  каталог — единственный источник товаров
tools/
  build.py         сборка в dist/ (только то, что едет на хостинг)
  images.py        нарезка картинок AVIF/WebP и превью товаров
  site-config.json ссылки на магазины и «Сотрудничество», метки, Метрика
  deploy.sh        выкладка dist/ по SSH
  publish-pages.sh предпросмотр на GitHub Pages (ветка gh-pages)
  check-live.sh    проверка живого сайта после выкладки
art/               исходники сцен (генерация Higgsfield), в git не хранятся
dist/              результат сборки, в git не хранится
dist-pages/        то же для предпросмотра на Pages
```

## Посмотреть локально

```bash
python3 tools/build.py --serve
```

Откроется на http://localhost:8420 — с теми же заголовками CSP, что на хостинге.

## Поменять товары

Всё в `data/catalog.json`. У товара: `id`, `line` (линейка), `name`, `volume`,
`desc`, `tags`, `wb.nmID`, `ozon.sku`, `img`. Правила текстов — в `PRODUCT.md`:
без лечебных заявлений, без «ботокса», без латиницы, кроме имени марки.

После правки:

```bash
python3 tools/images.py
```

```bash
python3 tools/build.py
```

`images.py` скачает новые превью с CDN Wildberries и положит к себе —
сайт не ходит за картинками на чужие серверы.

## Выкладка

Только через сборку, никогда не заливать папку проекта целиком.
Порядок, проверка и разбор ошибок — в `DEPLOY.md`.

## Требования

Python 3.9+ и Pillow 11.2+ (для AVIF). Больше ничего.
