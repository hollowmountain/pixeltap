# Выкладка на pixeltapi.ru

Хостинг — виртуальный Timeweb. Сейчас домен привязан алиасом к другому
сайту аккаунта и отдаёт 301 на него, своего SSL у домена нет. Порядок
ниже — один раз при запуске.

## 1. Перед запуском

1. Почты, реквизитов и имён продавцов на сайте нет — решение владельца
   от 24.09.2026. Для связи — чат продавца на площадках, для партнёров —
   ссылка «Сотрудничество» на ctmcosmetics.ru (`partner_url`). Если почта
   понадобится, её вписывают в `email` — она сама появится в подвале,
   вопросах и `security.txt`.
2. Сверить ссылку «Магазин на Ozon» (`stores.ozon`): это адрес, который
   давал владелец; какой кабинет за ним (oz-pixeltap или oz-beauty) —
   проверить в личном кабинете Ozon.
3. По желанию — ID организаций Ozon для меток внешнего трафика
   (`utm.ozon_org`): берутся в кабинете, раздел «Внешний трафик».

## 2. Панель Timeweb

1. **Сайты** → у сайта, к которому сейчас привязан домен, снять алиас `pixeltapi.ru` (и `www`).
2. **Сайты → Создать сайт**, папка `pixeltapi.ru`, привязать домены
   `pixeltapi.ru` и `www.pixeltapi.ru`.
3. **SSL-сертификаты** → бесплатный Let's Encrypt на `pixeltapi.ru`
   и `www.pixeltapi.ru`. Дождаться выпуска (обычно минуты).
4. **SSH** → включить доступ, добавить свой публичный ключ.
   Двухфакторный вход в панель — включить, если ещё нет: сайты одного
   аккаунта делят права на файлы, взлом одного даёт доступ к другому.

## 3. Выкладка

```bash
python3 tools/images.py
```

```bash
PT_SSH=логин@хост PT_PATH=/home/<буква>/<логин>/pixeltapi.ru/public_html tools/deploy.sh
```

Первый запуск — пробный: показывает, что поедет. Если всё верно, тот же
запуск с `--go`. Скрипт сам собирает `dist/` в режиме `--release`
и откажется работать, если путь не похож на папку `pixeltapi…/public_html`
(rsync с `--delete` при ошибке в пути снёс бы соседний сайт).

Без SSH — любым FTP-клиентом залить **содержимое `dist/`** (включая
скрытые `.htaccess` и `.well-known/`) в `pixeltapi.ru/public_html`.
Папку проекта целиком не заливать никогда: на Timeweb nginx отдаёт
`.txt/.js/.css` в обход `.htaccess`, закрыть случайно залитый файл нечем.

## 4. Проверка

```bash
tools/check-live.sh
```

Скрипт проверяет заголовки безопасности, редиректы http→https и
www→без www, что служебные файлы отвечают 404, свою 404, сертификат.
Все строки должны быть `ok`. Частые причины `FAIL`:

- **нет заголовков** — на хостинге выключен `mod_headers`; CSP остаётся
  в `<meta>`, но `frame-ancestors` и HSTS не работают → вопрос в поддержку;
- **бесконечный редирект** — Apache не получает `X-HTTPS`; закомментировать
  три строки http→https в `site/htaccess.tpl` и включить «Перенаправлять
  на HTTPS» в панели;
- **500 на всём сайте** — не разрешён `Options`; закомментировать строку
  `Options -Indexes -MultiViews` и проверить, что `/img/` не показывает список.

## 5. После запуска

- **HSTS**: через неделю без проблем поднять `max-age` в `site/htaccess.tpl`
  до `604800`, ещё через две — до `31536000`. `preload` не ставить.
- **Яндекс Вебмастер** и Google Search Console: добавить сайт, подтвердить
  **мета-тегом** (код — в `verify` в `tools/site-config.json`, затем пересобрать
  и выложить; HTML-файл подтверждения не нужен), отправить
  `https://pixeltapi.ru/sitemap.xml`, запросить переобход главной.
- **Панель Timeweb**: включить «Перенаправлять на HTTPS» — статику nginx
  отдаёт и по http, `.htaccess` её не видит.
- **Превью ссылок**: отправить ссылку себе в Telegram и VK — должна
  появиться картинка с товарами и заголовок.
- **GitHub Pages** (`hollowmountain.github.io/pixeltap/`) — там предпросмотр
  из ветки `gh-pages` (`tools/publish-pages.sh`), закрытый от поисковиков.
  После запуска pixeltapi.ru его лучше выключить (Settings → Pages), чтобы
  по старой ссылке не жила отстающая копия.
- **DNS** (панель Timeweb → DNS): добавить CAA `0 issue "letsencrypt.org"`;
  если почта на домене не используется — SPF `-all` и DMARC `p=reject`.

## Яндекс Метрика (когда понадобится)

Код уже готов: вписать номер счётчика в `metrika_id` и пересобрать —
появится окно согласия, счётчик грузится только после «Разрешить».
Юридически перед включением нужно:

1. Уведомление в Роскомнадзор об обработке ПД (pd.rkn.gov.ru), если
   оператора ещё нет в реестре.
2. Вернуть на страницу `privacy/` сведения об операторе и способ связи:
   со счётчиком и согласием сайт уже обрабатывает ПД, и политика без
   оператора закону не соответствует. Раздел про Метрику появляется сам.
3. Вебвизор не включать.
